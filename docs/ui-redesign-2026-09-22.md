# 画面UIのリニューアル（2026-09-22）

## 方針・対象

今回のデザイン実装は `src/main/resources/static/` のHTML・CSS・JavaScriptが対象。
監視判定・通知・録画・DB更新のロジックを追加変更する設計は採用せず、既存APIで表示する。
前回着手したバックエンド依存の画面機能は取り下げ、並行して追加された機能は保持した。

参考にしたサイト・情報：

- [YouTubeの画面構成](https://support.google.com/youtube/answer/2398242?hl=en-GB)：ホーム・登録チャンネル・ライブラリを分けるナビゲーション。
- [Twitchの配信一覧](https://www.twitch.tv/directory)：配信コンテンツを中心にしたカードの配置とアクセントカラー。

ロゴや素材のコピーは行わず、既存の録画サムネイル・実データを使用。

## 変更内容

- 共通：白を基調とした背景、紫のアクセント、アイコン付きサイドナビゲーション、余白・入力欄・ボタン・状態表示を統一。
- 狭い画面：ナビゲーションを横スクロールへ変更。表はセルを折り返さず表の中でスクロールする。
- ダッシュボード：集計の直後に配信中一覧を配置。設定は折りたたみに移動。容量0の項目を円グラフの凡例から省略（容量の表・棒グラフには保持）。
- 録画：検索とサムネイル一覧を先頭に配置。URLからの追加・容量管理・一括削除を折りたたみ内に移動。
- チャンネル：登録フォームをまとめ、名前検索は必要なときだけ展開。通知・録画条件は共通の保存／取消UIを使用。
- アクセシビリティ：現在ページの明示、本文へのスキップ、フォーカス表示、入力の読み上げ名、動きを減らす設定に対応。
- 既存サーバーのCSRF設定に合わせ、変更系リクエストとログインフォームに画面側でトークンを付ける。

## 確認

- `tsc -p src/main/resources/static/jsconfig.json --noEmit`：成功。
- `node --test src/test/js/channel-filter.test.cjs`：2件成功。保存後の再編集、取消、保存失敗、二重編集を確認。
- `./gradlew clean build javadoc`：成功（Javaテスト588件）。コンパイル・JavaDocの警告なし。テスト用JVMのクラス共有警告は1件あり。
- 最終反映：`./gradlew build -x test javadoc` 後に `bin/service.sh restart`。
- 実ブラウザ：ダッシュボード・録画・チャンネル・通知履歴・ログ・DB管理を幅390pxで確認。ページ全体の横はみ出し、重複ID、画面のエラー表示なし。
- 実データの削除、テスト通知、録画の開始・停止は行っていない。
